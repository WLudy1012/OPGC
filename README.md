# OPGC

`OPGC` 是一个面向传送带供电设计的桌面计算器，用来搜索“发电设备分组 + 分流器档位”方案，使系统长期平均供电满足目标负载，同时将浪费控制在可接受范围内。

当前程序提供图形界面，输入以下参数后自动搜索最优方案：

- `b`：单台发电机在满功率运行时的输出功率，单位为“每秒”
- `Q`：`Quantity demanded`，系统总用电功率，单位为“每秒”
- `aim`：允许的最大超出量，也就是 `P_avg - Q` 的上限

程序输出：

- 发电设备总数 `E`
- 每条主带承担的发电机数量
- 对应的 `xi`、`yi`、`Ti`
- 每台发电机的平均输出与工作状态（满功率或间歇）
- 总平均功率、超出量、浪费率
- 搭建方法说明

## 软件说明

这个工具解决的是“如何用若干条主带和串联分流器喂给一组发电机，使平均供电功率刚好覆盖负载”的组合优化问题。

图形界面基于 `ttkbootstrap` 构建，包含：

- 参数输入区：`b`、`Q`、`aim`
- 计算按钮、清空按钮、退出按钮
- 异步计算进度条
- 滚动结果面板

计算在后台线程执行，界面不会因为搜索而假死。

## 物理模型

程序严格采用以下规则：

### 固定参数

- 主传送带原生间隔：`2` 秒 / 个电池
- 单个电池总能量：`40 × b`
- 基地自带固定发电：`200 / 秒`
- 分流器效果：
  - 二分器：支路间隔乘 `2`
  - 三分器：支路间隔乘 `3`
- `xi`、`yi` 是从主带起点到发电机入口路径上经过的二分器、三分器数量

### 发电机平均功率

对某一条主带：

- `Ti = 2 × 2^xi × 3^yi`
- 当 `Ti ≤ 40` 时，发电机始终满功率运行，平均输出直接取 `b`
- 当 `Ti > 40` 时，发电机间歇运行，平均输出为：

```text
(40 × b) / Ti
```

注意：

- `Ti ≤ 40` 的情况不能套用 `(40 × b) / Ti`
- 这条规则在代码里是显式分支，不是统一公式

### 目标窗口

程序搜索满足下面条件的方案：

```text
Q ≤ P_avg ≤ Q + aim
```

其中：

- `P_avg` 是总平均供电功率
- `P_avg - Q` 是浪费量

优化优先级为：

1. 浪费量最小
2. 发电设备总数 `E` 更少
3. 主带数量更少
4. 分流器总数更少

## 搜索算法

程序没有直接暴力枚举“所有接线图”，而是把问题拆成“发电机模式选择 + 分组回溯”的组合搜索。

### 1. 生成档位表

先枚举所有可能的 `xi`、`yi`，计算对应的：

- `Ti`
- 单台平均输出
- 是否为满功率档

默认只保留 `Ti ≤ 2000` 的档位，这个范围已经覆盖当前程序使用的主要可行解空间。

### 2. 从最少发电机数开始搜索

先计算：

```text
E_min = ceil((Q - 200) / b)
```

然后从 `E = E_min` 开始逐个尝试。  
一旦某个 `E` 找到有效方案，程序就在这个 `E` 的所有候选里选最优解并立即停止，不再继续搜索更大的 `E`。

这符合“先最少发电设备数，再最小浪费”的规则。

### 3. 动态规划枚举模式组合

对于固定的 `E`：

- 把“每台发电机选一个模式”看成一层状态转移
- 用动态规划累计所有可能的总平均输出
- 对同一个累计输出，只保留更优的中间状态

状态里记录：

- 当前累计输出
- 已使用的模式集合
- 分流器总数
- 上一步来源

这样做的目的：

- 避免直接穷举所有分组 × 所有档位排列
- 对同一输出只保留更优代表状态
- 可以在最后回溯出“每种模式用了几台发电机”

### 4. 回溯分组

当某个累计输出满足：

```text
Q ≤ P_avg ≤ Q + aim
```

程序就从 DP 状态回溯出各模式使用台数，再整理成：

```text
[(ai1, mode1), (ai2, mode2), ...]
```

其中每一项表示“一条主带供 `ai` 台相同模式的发电机”。

### 5. 选最优解

在同一个 `E` 下，程序按下面的键排序：

```text
(overage, E, 主带数, 分流器总数)
```

第一个找到有解的 `E` 会立即返回其最优方案。

## 输出说明

程序结果区格式如下：

```text
【方案】
b=..., Q=...
E=总发电设备数
分组：
主带1：供...台，xi=...，yi=...，Ti=...s, 单台输出=...，满功率/间歇
...
总平均功率：...
超出：...（浪费率约...%）
搭建：
带1：主带→...
带2：主带→...
```

搭建描述的约定：

- `主带→二分器→三分器→...` 表示从主带起点到发电机入口的串联顺序
- 发电机从最后一个分流器的一个出口接出
- 其余未使用出口需要回流到电池源头或该主带入口，不能堵塞

## 运行方式

### 直接运行脚本

```powershell
python conveyor_power_calculator.py
```

### 打包为单文件 exe

```powershell
pyinstaller -F -w conveyor_power_calculator.py
```

构建产物默认位于：

```text
dist/conveyor_power_calculator.exe
```

python -m pip install ttkbootstrap pyinstaller
